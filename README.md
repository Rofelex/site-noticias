## Lendo o Código: Site de Notícias Simples

Este projeto é um **site de notícias estático e simples** construído fundamentalmente com **HTML e CSS**. Ele serve como uma demonstração de estrutura de página básica, layout e estilização minimalista.

-----

### 🚀 Sobre o Projeto

O objetivo deste projeto foi criar um *mockup* de um site de notícias, focando na **semântica do HTML** e no **design responsivo (básico) com CSS**. Ele não utiliza nenhuma linguagem de *backend* ou *framework* de *frontend* mais complexo, sendo ideal para quem está começando a aprender o básico da web.

#### Funcionalidades Chave:

  * **Estrutura Semântica:** Uso de elementos HTML5 como `<header>`, `<nav>`, `<article>`, `<aside>` e `<footer>`.
  * **Estilização com CSS:** Separação completa da apresentação (CSS) da estrutura (HTML).
  * **Layout de Colunas:** Exibição de notícias principais e barras laterais.
  * **Responsividade Básica:** Utilização de *media queries* para adaptar o layout a telas menores.

-----

### 💻 Tecnologias Utilizadas

Apenas as tecnologias essenciais para um site estático:

  * **HTML5** (Linguagem de Marcação)
  * **CSS3** (Folhas de Estilo em Cascata)

### 📂 Estrutura do Projeto

A organização dos arquivos é simples e direta:

```
nome-do-projeto/
├── index.html          # Página principal (Home)
├── css/
│   └── style.css       # Todas as regras de estilo
├── img/                # (Opcional) Diretório para imagens

```

-----

### 🛠️ Como Visualizar o Projeto

Por ser um projeto puramente estático, você só precisa de um navegador web:

1.  **Clone o repositório** (ou baixe os arquivos zipados).
2.  **Abra o arquivo `index.html`** no seu navegador de preferência (Chrome, Firefox, Edge, etc.).

Alternativamente, você pode usar uma extensão de servidor local no VS Code (como o Live Server) para simular um ambiente de hospedagem.

-----

### 💡 Próximos Passos e Possíveis Melhorias

Este projeto pode ser expandido de várias maneiras:

  * **Interatividade:** Adicionar JavaScript para *carrosséis* de notícias, um menu *hamburger* funcional ou um modo escuro (*dark mode*).
  * **Organização do CSS:** Refatorar o `style.css` usando metodologias como BEM ou CSS Modules para projetos maiores.
  * **Acessibilidade (A11y):** Melhorar a acessibilidade utilizando atributos ARIA e garantindo bom contraste de cores.
  * **Novas Páginas:** Criar páginas separadas para artigos completos (`artigo.html`), categorias ou uma página de contato.
